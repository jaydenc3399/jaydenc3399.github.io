SEP 11 Freedom Project Tom and Jerry

Content

The "Freedom Project" for SEP11 is a year-long project all about making something using JavaScript along with a third-party JS tool. The purpose of the freedom project is really just as the name implies which is letting your mind run free and making whatever you want. It brings out the creativity and that genuine hard work as it tests and hones all of our personal skills that we will most likely use in the future such as hard working, perseverance, determination, etc. For my project, I chose to independently study kaboom in order to help me make a game that was inspired by Tom and Jerry. This project was based on my imagination and experience with watching cartoons growing up as a child. Waking up everyday in the morning just to watch cartoons on my grandma's old television. Getting the nice thrill with all of the different varieties of cartoons. My project was created based on wanting others to not forget the amazing times as a child that we had, to cherish all of these moments as they are being replaced by numerous of things such as computers, i pads, mobile devices such as phones which print along social media and youtube shorts, tiktok reels, instagram reels, and more.

Context

My project was an inspiration from the cartoon Tom and Jerry where there is a cat and mouse sprite chasing one another and you have the option to either choose solo mode or multiplayer where in solo you try and reach a flag as a mouse to escape. In multiplayer two people, the left mouse using WASD to move then and X to shoot. WHile the cat on the right uses the arrow keys to move and N to shoot, trying to reach the goal of three while also dodging the obstacles. I was trying to make a fun interactive game that would be fun and also remind us of our childhood cartoons Tom and Jerry and just generally cartoons.

Challenges

I faced one challenge while creating my project which was the damage logic. In the beginning what I wanted to create was an invulnerability effect that would make it so the game is not rigged and you can just spam the shot until the person dies. I wanted to create a wait time for it, however when I first tested my code it didn't work, instead it did the complete opposite and created the logic where it always takes damage when hit by the laser or bullet. After looking for a while and double checking my work I found that I was missing the logic that checks if it was hit a second time, that was off generating the effect that constantly causes the player to take damage. So adding that back Checks for invisibility (ensures that the player can only take damage once per invincibility period.) So really double checking your work to make sure that you got all the parts and always taking a second look to catch things you might have missed the first time.

Takeaways

Some takeaways that I had for this project is to always be creative. What I mean by this is that I had an original idea for my project but after thinking about how boring it would be I ended up editing my game into something that was more creative. I started first with the idea of creating two balls that would fight each other then I started to think of ways to make it better and I ended up adding in sprites that resembled Tom and Jerry. So my takeaway is that it's okay to change your original plan if you think something will work out better and also let your imagination run free. The next steps that I have is trying to take in more feedback from others around the community and getting their input and jotting down ways that I can better improve my project because I know it is not fully the best. So really just trying to improve as needed and letting more people try and test my game to find either bugs or things to improve on.
